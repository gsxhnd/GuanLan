# 开发文档导读

本目录沉淀 GuanLan 的开发共识，建议按以下顺序阅读：

| 编号 | 文件 | 说明 |
|------|------|------|
| 01 | [product-scope](./01-product-scope.md) | 产品定位、边界、MVP 范围和核心流程 |
| 02 | [architecture](./02-architecture.md) | 系统架构、模块划分、数据流和 API 边界 |
| 03 | [domain-model](./03-domain-model.md) | 领域对象、任务状态和通用字段 |

| 06 | [open-questions](./06-open-questions.md) | 尚未定稿的产品与技术问题 |

## 与其他目录的关系

- **dev/**：定义开发共识，包括产品边界、架构、模型和路线图。
- **wiki/**：沉淀项目知识库，包括使用指南、模块说明、设计决策和实现方案。
- **design/**：提供 UI 设计提示词和表现层参考。
