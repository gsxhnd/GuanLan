# 待决策事项

本文档只记录尚未定稿、且会影响实现路径的产品与技术问题。已形成决策的问题应移出本文档，并更新到对应的 dev/ 或 wiki/ 文档中。

## 1. 数据源

- [ ] **A 股补充源**：除 Qlib 外，是否引入 akshare、tushare 或 baostock 作为冗余？
- [ ] **故障切换策略**：主数据源不可用时，是自动切换、手动切换，还是只告警？
- [ ] **复权策略**：前复权、后复权、不复权如何选择？是否需要多版本同时存储？

## 2. 数据与运维

- [ ] **DuckDB 默认路径**：数据库文件、缓存和导出文件的目录约定是什么？
- [ ] **数据保留策略**：历史行情、任务记录、日志和模型产物分别保留多久？
- [ ] **备份策略**：是否需要内置备份命令？备份频率和恢复流程如何设计？
- [ ] **日志策略**：日志格式、轮转方式、保留时长和日志入口如何统一？

## 3. 模型训练

- [ ] **训练频率**：每日、每周、手动触发，还是基于模型表现退化触发？
- [ ] **资源分配**：训练、推理和数据更新同时发生时，如何限制 CPU/GPU/内存占用？
- [ ] **评估基准**：采用哪些指标判断模型是否可用于每日分析？

## 4. 前端与交互

- [ ] **响应式范围**：当前是否只保证桌面端，还是需要兼顾平板？
- [ ] **状态管理方案**：React Context、Zustand、Jotai 或其他方案如何选择？

## 5. 安全与配置

- [ ] **API 鉴权**：本地单用户场景是否需要鉴权或本机访问限制？
- [ ] **敏感配置**：数据源 API key 等信息使用环境变量、`.env` 还是配置文件？
- [ ] **数据加密**：DuckDB 文件是否需要加密，还是依赖本机磁盘权限？

## 6. 工程质量

- [ ] **测试策略**：单元测试、集成测试和 E2E 测试分别覆盖哪些核心路径？
- [ ] **回测验证**：是否需要与 Qlib 内置回测结果做交叉验证？
- [ ] **CI/CD**：是否需要 GitHub Actions 或其他 CI 流水线？

## 7. 后续功能

- [ ] **通知渠道**：告警只在 Web GUI 内展示，还是支持系统通知、邮件或其他渠道？
- [ ] **市场扩展**：港股、加密货币等市场的接入优先级如何排序？
- [ ] **更高频能力**：是否以及何时引入盘中数据、实时分析或流式特征链路？

## 8. 投资组合扩展

- [ ] **资金加权回报率**：是否要求用户录入期初/期末快照并计算简易资金加权回报率？
- [ ] **送股与转增**：送股、转增字段已预留，何时纳入持仓数量和成本计算？
- [ ] **费用拆分**：当前交易费用为总费用字段，后续是否拆分佣金、印花税和其他费用？
- [ ] **券商导入**：是否支持从券商导出的交易流水批量导入？
